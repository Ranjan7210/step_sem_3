# Assignment Day 3 - Object-Oriented Programming Practice

This directory contains the solutions for the five programming questions of Day 3, focused on core Object-Oriented Programming (OOP) concepts in Java.

## 📁 Files included

- [pg1.java](pg1.java): **M1. From Parallel Arrays to a Class – Library Inventory**
  - Demonstrates how to replace parallel arrays with an array of objects of a custom `BookInventory` class.
- [pg2.java](pg2.java): **M2. Encapsulated Payroll Account**
  - Focuses on data encapsulation using `private` fields, data validation logic, and read-only access.
- [pg3.java](pg3.java): **M3. Overloaded Constructors for an Employee**
  - Explores constructor overloading and constructor chaining using `this()`.
- [pg4.java](pg4.java): **M4. Reference Copies and a Shared Exam Hall Ticket**
  - Compares reference copying (alias) versus creating a separate instance (content equality vs object identity).
- [pg5.java](pg5.java): **M5. Instance vs Static: Splitting an Employee Class Correctly**
  - Demonstrates static class members (variables and methods) versus instance members.
